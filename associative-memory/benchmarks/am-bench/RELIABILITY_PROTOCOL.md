# 查询扰动能否诊断并纠正检索？

状态：2026-09-06，首次数值运行前冻结。机制筛选实验，不是论文复现或创新性证明。

问题：在记忆、温度和更新公式固定时，沿竞争记忆方向扰动查询，是否比同预算随机探测和初始分数间隔更能识别失败？固定多数票能否产生净纠错？

模型复用 `am_bench.models.modern.ContinuousModernHopfield.readout`。每次读出为连续状态，不二值化；固定 12 次反馈。终态与存储记忆的内积最大者作为预测 ID，因此本实验测量身份检索，不声称逐坐标恢复。原始查询最近邻为强基线。另运行 108 次单轨迹更新，匹配原始检索加 8 条探测轨迹的矩阵乘法预算；方向生成、排序、诊断开销另外记录在墙钟时间中。

固定网格：N=32、128；P=64；独立 ±1 记忆和 32 对近邻记忆（每对相差 N/8 个比特）；随机种子 0..7；每个记忆库均匀无放回选择 16 个目标。查询条件为干净、加标准差 1.0 或 1.6 的高斯噪声，以及随机连续四分之一坐标替换为标准差 3 的高斯噪声。初始查询归一化至范数 sqrt(N)，后续动力学不归一化。beta=1/sqrt(N)，不搜索温度。

每个查询有 4 个切向方向，分别探测正负两侧，共 8 条轨迹。球面角半径为 0.10、0.25 弧度（0.10 为主要结果，0.25 为预定敏感性检查）。三个方向规则：

- guided：基线最终预测记忆，加初始查询分数最高的其他 3 条记忆。
- shuffled：保留同一个基线预测记忆，其他 3 条从其余记忆无放回随机抽取；这是随机候选对照，不要求恰好避开真实竞争者。
- random：4 条各向同性随机切向方向。

每条记忆方向均先去除查询的径向分量再归一化；退化方向改用随机切向方向并记录数量。同一查询、方法的方向在两个半径下复用。探测全部从扰动后的原始查询出发。预测、方向选择、多数票函数均不接收目标标签。标签只在造查询和最终评估时使用。

主要诊断量为 8 条轨迹中预测 ID 不同于原预测的比例。它不是错误概率。对照量为初始 top-2 分数负间隔、初始注意力归一化熵。主要指标是保留最可信 80% 查询后的错误率；分数并列在边界处采用分数权重，计算随机打破并列的期望风险，不根据标签择优。按 N、记忆类型、噪声分别报告；统计不把一个库中的查询视为独立种子。配对差值跨 8 个记忆库种子汇总，种子 bootstrap 2000 次给出探索性 95% 区间，无多重比较校正。

唯一纠错规则：8 条探测有严格多数（至少 5 票）才选择该记忆，否则保留原预测。不用标签挑赢家，不寻找最好半径。分别统计错改对、对改错、净正确率变化；两种错误记忆之间的改动不算纠正。干净查询用于检查误伤。

运行上限：完整网格 32 个记忆库、2048 条查询，每条 6 个方法/半径分支，共 12288 条评估记录；一个冻结网格，不依负结果追加参数扫描。预算终态不叫固定点，额外一步残差用于报告是否达到 1e-8；此观测步不参与预测，各探测分支的观测开销相同。

产物：源代码、带中文字体和 a/b/c/d/e/f 注释的 notebook、配置与代码指纹、不可覆盖的批次 JSON、可重建统计和图。先验证批量更新与已有标量实现一致、球面扰动、多数票和并列风险，再运行网格。若 guided 未超越简单分数与同预算对照，或纠错误伤抵消收益，则停止这条规则，不包装成成功；真实数据与经典 Hopfield 作为后续独立阶段，当前不主张外部效度。

来源：现代 Hopfield 更新来自现有仓库模型。会议议程中的局部能量几何/可靠性问题提供研究动机；本实验是单查询扰动，不是每条记忆的径向非谐性指标复现。也没有实现 Context-Gated Associative Retrieval 的上下文门控。
