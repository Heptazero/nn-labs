# 查询探测实验：没有观察到多数票纠错收益

日期：2026-09-06。状态：冻结网格已在本地 CPU 完整执行；负结果。经典 Hopfield、真实数据和 Colab 点击验收均未执行。

本轮支持一个有限判断：固定现代 Hopfield 的查询方向探测，在部分条件下比随机方向更能识别错误，但严格多数票没有救回任何错误。不支持把它当成已经有效的自适应相似函数。

## 实际做了什么

[Notebook](./notebooks/retrieval_reliability.ipynb) 使用 1982 实验的 a/b/c/d/e/f 组件分层、中文角色注释和 Noto CJK 字体。模型直接复用 [`ContinuousModernHopfield.readout`](./src/am_bench/models/modern.py#L43)，查询批处理经数值测试与既有标量及迭代实现一致。

[冻结协议](./RELIABILITY_PROTOCOL.md) 在第一次数值运行前写入：32 个记忆库、2048 条查询，每条查询三个方向规则、两个角半径，共 12288 条记录。方向规则和多数票不接收目标 ID；目标只用于生成带污染查询和事后评估。主要半径为 0.10，0.25 不用于事后挑最好结果。

这里的“调整”发生在输入查询上。存储记忆、beta 和更新公式都固定，没有参数微调，也没有自适应相似度矩阵。探测是检验推理时纠错可能性的第一步。

## 纠错结果

每个设置都评估同一组 2048 条查询，不能把六行相加当作独立样本量。

| 方向规则 | 角半径 | 错改对 | 对改错 | 净变化条数 |
|---|---:|---:|---:|---:|
| guided（主要设置） | 0.10 | 0 | 1 | −1 |
| guided | 0.25 | 0 | 0 | 0 |
| random | 0.10 | 0 | 1 | −1 |
| random | 0.25 | 0 | 2 | −2 |
| shuffled | 0.10 | 0 | 0 | 0 |
| shuffled | 0.25 | 0 | 4 | −4 |

主要设置的净正确率变化是 −1/2048，即 −0.0488 个百分点。不能把“未发生改答”解释成纠错有效。

## 诊断与便宜对照

在 N=128、块污染条件下，每种记忆结构有 8 个库 × 16 条查询。以下为各库保留最可信 80% 后的平均错误率，越低越好；边界并列采用等概率选择的期望。

| 记忆结构 | guided | 初始分数间隔 | 随机方向 | 随机候选 |
|---|---:|---:|---:|---:|
| 独立记忆 | 5.43% | 1.76% | 7.63% | 9.55% |
| 成对近邻记忆 | 1.76% | 2.73% | 5.06% | 3.97% |

独立记忆中，guided 相对分数间隔更差 3.67 个百分点，配对种子 bootstrap 95% 区间为 [0.68, 7.44]。成对记忆中，差值为 −0.98 个百分点，区间为 [−3.65, 1.24]，跨零。guided 对随机方向的优势并不等于对便宜分数的优势。八个种子的区间仅用于探索，没有多重比较校正。

## 基线失效及范围限制

N=32、beta=1/sqrt(N)、P=64 时，十二步读出对干净查询的正确率只有独立记忆 2.34%、成对记忆 1.56%，而原始最近邻为 100%。这一网格区域没有通过“存入模式可正常检索”的基线检查。它可以展示稳定错误的失败边界，不能用于证明有效工作区间中的普遍结论。本轮没有根据结果改温度重新寻找成功点。

N=128 的块污染条件中，十二步检索正确率分别为独立记忆 89.06%、成对记忆 91.41%；原始最近邻为 99.22%、95.31%。延长到 108 步的身份正确率与十二步相同。因而当前瓶颈包含反复读出对原始查询信息的损坏。多数票甚至没有超过原检索，更没有超过最近邻。

十二步终态不一定是固定点：N=128 的成对记忆在本次所有查询中均未达到一步残差小于 1e-8。报告的是固定预算的身份检索，不是收敛盆地的完整测量。近似等算力只匹配核心读出矩阵运算，不匹配方向生成和诊断的墙钟开销。

从数据假设看，高斯条件本来就给最近邻很强的优势：查询由某条等范数记忆加各向同性高斯噪声产生，归一化不改变内积排序（实现：[`c1_make_queries`](./src/am_bench/reliability.py#L60)）。在等先验的这一生成模型下，欧氏最近邻是最大似然选择。仅增加迭代或多数投票，并没有凭空增加识别目标的信息。这是依据实验生成过程的解释，不是额外的真实数据证据。

## 结论与停止决定

停止当前“方向探测 + 严格多数票”规则，不追加半径和温度搜索。已有结果不足以支持纠错价值，也不足以支持比简单间隔更可靠的普遍诊断能力。

如果以后重开实验，需要先明确额外信息从哪里来，例如可观测的缺失坐标 mask、已知污染模型或独立上下文，再检验这些信息能否改变正确候选的排序。那会是新的冻结协议；当前没有执行，也不保证会成功。经典 Hopfield 需要离散比特扰动及独立验证，不能直接外推。
