# Hopfield 三模式曲率门：结果

状态：`已在本地完整执行 / 2026-09-07`。

## 判定

冻结判定为 `PASS_RATE_AND_CURVATURE_GATE`。按预注册规则，`β=8` 下的
自由松弛速率与局部扰动速率都能区分纯模式和三模式多数混合态，局部拟合
速率也达到了与 Jacobian oracle 的最低相关要求。

这只说明“可以进入下一阶段”。它没有证明实时反 Hebb 联合动力学会收敛，
也没有证明速率是最好的门控信号。

## 主结果

| 设置 | 合格库 / 256 | 纯模式速率中位数 | 混合态速率中位数 | 五折平衡准确率 | 五折 AUC | 配对效应量 | 通过 |
|---|---:|---:|---:|---:|---:|---:|:---:|
| `β=8`，从二值状态自由松弛 | 32 | 0.9994 | 0.8337 | 0.828 | 0.929 | 1.039 | 是 |
| `β=8`，平衡点附近匹配扰动 | 32 | 1.0000 | 0.9373 | 0.828 | 0.867 | 0.940 | 是 |

两项的混合态都衰减得更慢。自由松弛的配对平均差 95% bootstrap 区间为
`[0.0898, 0.1794]`；局部扰动为 `[0.0509, 0.1048]`。固定拟合窗中，满足
`R²≥0.95` 的轨迹比例分别为 `1.000` 和 `0.995`。局部拟合速率与
Jacobian 最慢收缩率的 Spearman 相关为 `0.744`。

## 两个不能省略的反证

第一，初始速度基线更强。它只看 `t=0` 的 `||dx/dt||`，在自由松弛任务上
达到平衡准确率 `0.844`、AUC `0.957`，都高于自由松弛的拟合衰减率。这意味着当前
结果尚未证明“沿轨迹估计曲率”提供了初始局部场之外的新增信息。

第二，适用范围很窄。`β=8` 时只有 32/256 个固定模式库同时保留三个纯
吸引子和指定混合吸引子。其余库没有被替换或重采样：203 个库出现身份
错误且吸引子合并，20 个出现身份错误，1 个只出现吸引子合并。这个门目前
只对 12.5% 的合格库有定义。

## 温度邻域

| 设置 | 合格库 | 自由松弛 AUC / 通过 | 局部扰动 AUC / 通过 |
|---|---:|---:|---:|
| `β=6` | 9 | 0.790 / 否 | 0.951 / 否（样本不足） |
| `β=8` | 32 | 0.929 / 是 | 0.867 / 是 |
| `β=10` | 32 | 0.931 / 是 | 0.767 / 否 |

因此，“`β=8` 的必要条件通过”是可复核的；“曲率门普遍成立”仍然不成立。
这里的 Jacobian 最慢收缩率是局部线性稳定性的代理。因为所用向量场不是
欧氏度量下直接写成的梯度流，本文不把它偷换成一般意义上的 Hessian
曲率定理。

把平衡点积分步长从 `0.03` 减半到 `0.015`、步数加倍，并把轨迹步长从
`0.01` 减半到 `0.005` 后，合格库仍为 32，两个主 AUC 分别仍为 `0.929`
和 `0.867`，最终判定不变。主结果不是积分步长造成的数值假象。

## 下一道最小关卡

联合动力学若继续，必须同时带上三个门：无门控、初始速度门、衰减率门。
只有衰减率门在相同削弱预算下比初始速度门减少更多“假坑未逃出”，同时
不增加“真记忆逃出”，才能把贡献归给轨迹速率。否则更简单的初始速度已经
解释了结果，应停止“在线曲率”叙事。
