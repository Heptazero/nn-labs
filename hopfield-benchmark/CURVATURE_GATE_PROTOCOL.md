# Hopfield 三模式曲率门：冻结实验协议

状态：`v1 / confirmatory gate`；冻结日期：2026-09-07。

## 唯一主问题

在 `N=20, P=3` 的经典 Hebb 记忆库中，只观察连续检索轨迹前缀的
`||dx/dt||`，能否在未见过的模式库上区分纯记忆与三模式多数混合态
`sgn(ξ¹+ξ²+ξ³)`？

主动力学固定为

`dx/dt = -x + tanh(β W x)`，`W = (1/N) Σ ξᵘ ξᵘᵀ`，且 `W_ii=0`。

这里的结论只适用于这套连续 Hopfield 动力学。离散符号更新没有
`dx/dt`，不能把本实验的速率直接移过去。

## 为什么不是 N=2,3

这里的 `N` 是神经元数，`P` 是存储模式数。主实验固定 `N=20, P=3`。
三个模式是构造奇数多数混合态的最低模式数；`N=2,3` 既没有可用的
有限尺寸余量，也容易让混合态与某个纯模式重合。

## 冻结配置

- 确证集使用从未参与温度摸底的 256 个模式库：seed `10000..10255`。
- 主温度 `β=8`。摸底仅用 seed `0..255` 确认该温度能提供足够多的
  四吸引子模式库；确证结果不回头改温度。
- `β=6,10` 只做邻域稳健性检查，不决定主结论。
- 每个模式库同时从三个纯模式和一个多数混合态出发。
- 拟合窗固定为 `t∈[0.25,1.25]`，拟合
  `log ||dx/dt|| = a - r t`。分类器只能读取标量 `r`。
- 为排除“离平衡点远近”冒充曲率，增加一个机制对照：先求四个连续
  平衡点，再对四者施加相同的 8 个欧氏单位方向、相同范数 `0.05` 的
  扰动；用 `t∈[2,4]` 的速率做同一检验。
- Jacobian 最慢收缩率只作为 oracle 验证，不提供给分类器。

## 样本资格与失败保留

固定的 256 个模式库全部写入 `bank_status.csv`。只有同时满足以下条件的
模式库能回答“真假稳定吸引子的衰减率是否不同”：

1. 四条轨迹收敛；
2. 终态符号分别等于三个纯模式和指定混合态；
3. 四个终态互不相同；
4. 四个平衡点的 Jacobian 最大实部均小于 `-1e-5`。

不合格库不重采样、不补齐，也不进入真假吸引子分类；资格率本身作为结果
报告。至少需要 30 个合格模式库，否则门直接失败。

## 预注册通过条件

以模式库为独立样本。每个库先分别汇总纯模式与混合态速率，再按
`pattern_seed mod 5` 做跨库五折验证。训练折只决定方向与两类中位数的
中点阈值，测试折不调参。

主门同时要求：

- 至少 30 个合格库；
- 至少 90% 的轨迹在固定窗内达到 `R²≥0.95`；
- 速率门的平衡准确率至少 `0.75`，AUC 至少 `0.80`；
- 配对速率差的 95% bootstrap 区间不跨 0；
- 配对效应量 `|d_z|≥0.80`。

“曲率”解释还必须让匹配局部扰动通过同一门，并使在线拟合速率与
Jacobian oracle 的 Spearman 相关至少为 `0.70`。

判定只有三种：

- `KILL_RATE_GATE`：自由松弛速率本身不可用，停止联合动力学；
- `RATE_SIGNAL_ONLY_CURVATURE_CLAIM_FAILS`：速率可分，但曲率解释不成立；
- `PASS_RATE_AND_CURVATURE_GATE`：只允许进入下一阶段，并不等于反 Hebb
  联合动力学已经有效。

## 运行与复核

```bash
python hopfield-benchmark/run_curvature_gate.py
python -m unittest tests.test_curvature_gate
```

结果目录保存全部模式库资格、每条轨迹的拟合值、冻结配置摘要和最终判定。
脚本不含“直到得到正结果”为止的循环。
