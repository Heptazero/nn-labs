# Hopfield dynamic geometry

This folder contains small, Colab-ready experiments that adapt time-varying
pullback-metric analysis to Hopfield retrieval dynamics.

- `experiment_00_pullback_metric_colab.ipynb`: one-dimensional calibration
  experiment with two memories in a continuous Hopfield network.

The first notebook is a method sanity check, not a reproduction of the RNN
dynamic-warping paper and not evidence of a new Hopfield result.
